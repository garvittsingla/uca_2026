# First Week

## 1. ClangFormat

`clang-format` is a tool to format C/C++/... code according to a set of rules and heuristics. Like most tools, it is not perfect nor covers every single case, but it is good enough to be helpful. It is just a simple CLI tool to format C/C++ code. 


## 2. diff Command

`diff` - compare files line by line

A simple diff tool that shows changes between two versions of files, similar to `git diff`.

## 3. Pipe Command

In Linux, the pipe (`|`) takes the stdout of one command and pushes it to a buffer, then feeds it into the stdin of another command.


## 4. Xargs

In Linux, a program can take input in 2 ways:
- stdin
- Command line arguments

The pipe sends data to a program as stdin, but some programs like `rm` expect command line arguments and cannot take input from a pipe. This is where `xargs` comes in - it takes stdin and feeds it as command line arguments to a program.
