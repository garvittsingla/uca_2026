## 1. ClangFormat
clang-format is a tool to format C/C++/... code according to a set of rules and heuristics. Like most tools, it is not perfect nor covers every single case, but it is good enough to be helpful.
it is Just a simple CLI tool to format the c/c++ code 


## 2. diff command 
diff - compare files line by line
just a simple diff tool that changes between the 2 versions of files , just like git diff

## 3. Pipe command
In Linux it simply takes the stdout of one commnand and pushes it to a buffer, then it just takes that and feeds into the stdin of different command


## 4. Xargs 
In linux a file can take input in 2 types 
### 1. stdin
### 2. Command line arguments

Pipe sends the data to the program in form of stdin , but some programs like ```rm``` expect a command line arguments and cannot take argument from pipe, here command line utilities/tools like xargs came which take stdin and feed like a command line argument to a program
