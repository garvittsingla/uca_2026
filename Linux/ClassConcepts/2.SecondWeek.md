# Second Week

This week covers low-level API calls like `read()`, `write()`, and file descriptors in detail.

These are the system calls (`open`, `read`, `write`, `close`) which are exposed in these header files: `<unistd.h>`, `<fcntl.h>` 

## File Descriptor (FD)

A file descriptor is a non-negative integer provided by the OS to identify a file. It acts like an index to the file. Every process in Linux has its own FD table. In Linux, everything is a file - sockets, keyboard input streams, etc. - so programs can use FDs to reference these files.

## Buffer

A buffer is a chunk of memory created by the user. The system copies data from the file descriptor into this buffer. Since data gets loaded directly into RAM, using buffers allows us to handle large files piece by piece rather than loading everything into memory at once.
