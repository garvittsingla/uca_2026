# 2nd week


This week involves , low level API calls like read(), write(), file descriptors in detail

These are the syscalls  `open`, `read`, `write`, `close` which are exposed in these header definations `<unistd.h>`, `<fcntl.h>` 

## Fd -> This is a non negative integer provided by the OS , to tell about a file and it is just like a index to the file , Every process in linux has its own fd table where it just executes, Everything linux is a file , so every socket, every input stream from keyboard , everything is a file which can be used by program to make a FD and reference that file everytime

## Buffer 
Buffer is a chunk of memory that is created by us, from where the system will copy from the fd andf put it in our specified buffer(it gets directly loaded into the RAM, so we just takes buffer by buffer so that we don't directly put a very large file directly into the RAM)
