# lseek

`lseek` gives you manual control to move the file offset anywhere you want without reading or writing any actual data.

```c
off_t lseek(int fd, off_t offset, int whence);
```

**Parameters:**
- `fd`: The file descriptor returned by `open()`
- `offset`: A signed integer (`off_t`) representing the number of bytes to move. Can be positive or negative depending on `whence`
- `whence`: The reference point for the calculation

| Directive | Reference Point | How Offset is Calculated | Example Usage |
|-----------|-------------------|----------------------------|----------------------------------|
| `SEEK_SET` | Beginning of file (Byte `0`) | `New Offset = 0 + offset` | Jump directly to a specific byte location |
| `SEEK_CUR` | Current cursor location | `New Offset = Current Offset + offset` | Skip forward or rewind relative to current position |
| `SEEK_END` | End of file (File Size) | `New Offset = File Size + offset` | Seek relative to EOF (e.g., jump to the end) |
