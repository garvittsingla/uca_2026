# Inode, Soft Links and Hard Links

## Inodes

An inode (index node) is a filesystem data structure that represents a file and stores its metadata.

An inode stores:
- Permissions
- Owner/group
- Size
- Timestamps
- Link count
- Data location information

Note: An inode does not normally store the filename; directories map filenames to inode numbers.

```bash
ls -i file.txt       # Show inode number
stat file.txt        # Detailed inode/file information
```

## Hard Links

A hard link is another filename pointing to the same inode.

```bash
ln original.txt hard.txt
```

```
original.txt ──┐
               ├──→ Inode 123 → Data
hard.txt ──────┘
```

## Soft Links (Symbolic Links)

A soft link (symlink) is a separate file that stores the path of another file.

```bash
ln -s original.txt soft.txt
```

```
soft.txt → Symlink Inode → "original.txt" → Original Inode → Data
```
